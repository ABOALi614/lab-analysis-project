# 🩸 محلّل صورة الدم الكاملة (CBC) بالذكاء الاصطناعي | CBC Analyzer

موقع بياخد **قيم تحليل CBC** (8 قياسات) ويقدّر أقرب نمط من 4 حالات: **سليم / أنيميا نقص الحديد / أنيميا كبيرة الكريات / أنيميا طبيعية الكريات والصبغة**، ويعرض مقارنة قيمك بالمدى الطبيعي ومعلومات مبسطة (عربي وإنجليزي).

> ⚠️ مشروع تعليمي فقط، النتيجة ليست تشخيصًا طبيًا.

---

## 🔁 الفرق عن مشروع الأشعة
| | مشروع الأشعة | المشروع ده |
|---|---|---|
| المدخلات | صورة MRI | 8 أرقام من تحليل CBC |
| الموديل | MobileNetV2 (TensorFlow) | Random Forest (scikit-learn) |
| ملف الموديل | `.keras` | `.joblib` + `model_meta.json` |
| التدريب | محتاج GPU، 15–30 دقيقة | بدون GPU، دقيقة أو اتنين |

## 🚀 الخطوات

### الخطوة 1: تدريب الموديل على Google Colab (مجاني)
1. ادخل على https://colab.research.google.com ← **File ← Upload notebook** ← ارفع `training/train_model_colab.ipynb`.
2. **Runtime ← Run all**. (مش محتاج GPU.)
3. لو الخلية التالتة طلبت تسجيل Kaggle: اعمل حساب مجاني على https://www.kaggle.com ← **Settings ← API ← Create New Token**، وحط الـ username والـ key في المربع.
4. لو الخلية الأولى قالت "اعمل Restart session": **Runtime ← Restart session** ثم **Run all** تاني.
5. **اقرا مخرجات الخلية الرابعة**: فيها عدد العينات لكل حالة، وفحص الوحدات. لو ظهر ⚠️ جنب أي قياس، ابعتهالي قبل ما تكمل.
6. في الآخر هينزل `cbc_results.zip`. فك الضغط:
   - `cbc_model.joblib` و `model_meta.json` ← **انسخهم داخل فولدر `model/`**.
   - `project_report_ar.html` ← **التقرير العربي جاهز بالأرقام الحقيقية** (افتحه في المتصفح، ومنه Print ← Save as PDF).
   - `confusion_matrix.png` و `feature_importance.png` و `results.json` ← للتقرير والعرض.

### الخطوة 2 (اختيارية): تجربة الموقع على جهازك
```bash
pip install -r requirements.txt
streamlit run app.py
```
(Python 3.10 أو 3.11 أو 3.12)

### الخطوة 3: الرفع على Hugging Face Spaces (مجاني)
1. حساب على https://huggingface.co ← **New ← Space**.
2. اكتب اسم، **SDK: Streamlit**، **Hardware: CPU basic (Free)**، **Public** ← **Create Space**.
3. **Files ← Add file ← Upload files**، واسحب **كل محتويات** فولدر المشروع (بما فيه فولدر `model` وفيه الملفين، و`README.md` و`.streamlit`) ← **Commit changes**.
4. استنى لحد ما الحالة **Running**.

> الاستضافة المجانية بتنام لو محدش استخدم الموقع فترة، وبتصحى لما حد يفتحه.

## 🧠 دروس من مشروع الأشعة اتطبقت هنا
- **إصدارات متثبتة:** نوتبوك التدريب بيثبّت `scikit-learn==1.6.1` وده نفس الموجود في `requirements.txt`، والموقع بيحذّرك لو الإصدارين اختلفوا.
- **مفيش تسريب في الاختبار:** حذفنا الصفوف المكررة قبل التقسيم، عشان الدقة تبقى حقيقية.
- **فحص الوحدات:** النوتبوك بيتأكد إن القياسات بنفس الوحدات اللي الموقع متوقعها.
- **الموقع مش بيقبل أي رقم:** فيه حدود لكل قياس، وفحص إن الأرقام متسقة مع بعضها (MCV وMCH وMCHC بتتحسب من التانيين)، وتحذير لو القيم برا نطاق التدريب أو الثقة قليلة.
- **التقرير بيتولد تلقائي** بالأرقام الحقيقية، مفيش حاجة تتنسخ بإيدك.
